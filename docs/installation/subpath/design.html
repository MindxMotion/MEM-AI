Resolved interfaces and ownership

Canonical prefix P is empty for absent/empty or exactly /; otherwise it is an absolute local path of nonempty ASCII segments matching [A-Za-z0-9_-]+, with at most one optional trailing slash removed. Reject whitespace/control characters, scheme/host/userinfo, protocol-relative paths, backslashes, percent escapes, dot/traversal segments, repeated slashes, query and fragment. Do not decode or silently repair invalid configuration. Thus /new-api and /new-api/ both become /new-api. Build-time input is VITE_APP_BASE_PATH; backend runtime input is APP_BASE_PATH, empty by default. Invalid configuration fails the build/startup, never falls back to root.

Use one small pure frontend path module shared by Rsbuild and browser callers; it must not evaluate browser globals when imported by config. The Go equivalent belongs in existing common/session_cookie.go, not an attempt to import TypeScript or a new configuration framework. Both use the same examples/grammar. Owned browser-path joining preserves encoded suffix/query/hash and is idempotent only on the exact P or P/ boundary. Absolute external URLs and blob/data sources are not mount inputs. API endpoint strings remain unmounted when passed to Axios; public-site fallback is window.location.origin + P, without a trailing slash. Never append P to an explicit configured server_address or use new URL('/v1', siteBase), which discards its path.

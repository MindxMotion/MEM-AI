Does native basepath preserve New API route/auth semantics?

Hypothesis P1: TanStack basepath plus Rsbuild assetPrefix and existing Axios baseURL can serve the actual application beneath /new-api/, with a bounded list of explicit non-router URL owners and no global rewrite.

Environment: Windows, baseline 42e694eb, scoped official Bun 1.4.0 and Go 1.26.1; frontend dependencies must come from unchanged bun.lock. Local proof uses disposable frontend source copy and loopback-only browser fixture; no production or shared database access.

Budget: 30 minutes from 07:45 +08:00 on 2026-10-12. Stop if locked dependencies cannot restore, baseline cannot build, actual browser cannot run, native router requires unbounded href/path rewrites, or proof would require billing/schema changes. Do not promote code before an ADOPT decision.

Threshold: actual built frontend browser loads/navigates/reloads prefixed home, setup and login; observed owned HTTP and SSE requests stay within prefix; same proof passes root mode. Capture safe path/status summaries only. This establishes mounting feasibility, not backend auth or relay correctness; those remain implementation gates.

Initial observed red evidence: bun run build:check failed because Bun was absent; go version failed because Go was absent. Official pinned download probes succeeded, scoped Bun reports 1.4.0; scoped Go reports go1.26.1 windows/amd64. No machine-wide PATH changes.

Observed: the locked root frontend passed strict TypeScript and production build using the matching x64 Bun runtime. The native router tracer passed root and prefixed input/output semantics. Real Edge passed sign-in reload, login navigation and setup reload in both modes with a loopback-only synthetic backend; the successful prefixed run had no escaping owned requests and no page errors.

The first prefix build loaded resources correctly but management requests escaped to root because loadEnv public variables were not passed into source.define. Explicit environment injection fixed that failure. The isolated proof also prefixes the default logo. A login-navigation wait timed out once under build contention; a subsequent run passed. This is not backend authentication, streaming or exhaustive page evidence.

Decision: ITERATE for the original full threshold; ADOPT the native router, asset-prefix and Axios-base approach for basic mounting. Raw streaming, callbacks, cookie paths and exported addresses remain production implementation and verification requirements. No production-path edits were promoted. Proof code remains in the ignored .local-tests/subpath directory; browser fixtures record paths only, never request bodies or credentials.
